# Delivery roadmap

- Phase 0: audit the source; preserve historical bytes; verify reusable inference and tournaments.
- Phase 1: immutable configurable networks, exact RPS evolution, selection/mutation, second environment, 40-generation run.
- Phase 2: strict configuration, atomic SQLite history/checkpoints, import/export, interruption equivalence.
- Phase 3: measured NumPy/Numba paths, bounded process queue, replicates/sweeps, endurance and 1/2/4-worker comparisons.
- Phase 4: local dashboard, inspector, lineage, tournament laboratory, settings, browser/API acceptance.
- Release gate: 100-network 1,000-generation run, pause/restart/resume, historical preservation, full tests, measured report. No untested feature counts as completed.

Current evidence and remaining work are recorded in DEVELOPMENT_PROGRESS.md. Future v2.1: crossover interfaces and controlled sexual-reproduction experiments; no future feature is part of this release.
